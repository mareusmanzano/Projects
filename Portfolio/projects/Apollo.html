Apollo

  • Redis

    • RoleBackend developer
    Timeline3 weeks, 2023
    StackPython, FastAPI, Redis
    StatusLive, powering 3 apps

    Overview

  • Purpose: Centralizes infrastructure health tracking for enterprise web applications and servers into a single interface.
  • Automation: Executes scheduled background ping checks every 5 minutes to maintain accurate operational status.
  • Key Value: Eliminates manual checks by delivering immediate, real-time alerts for service disruptions and downtime.

    • The problem

    A few indie developer friends kept hitting rate limits and inconsistent response shapes from raw weather APIs. Everyone was solving the same caching and normalization problem separately.

    What I built

    Apollo is a real-time fire detection and reporting system designed to enhance emergency response efficiency.Using AI powered image recognition, Apollo ensures faster, more accurate fire incident reporting. the app enables users to capture and submit fire reports with real-time geotagging, while responders receive instant notification for swift action. Apollo streamlines communication, minimizes response delays, and improves public safety.

    What I learned

    This project pushed me to think seriously about cache invalidation strategy and about designing an API endpoints and database schemas to ensure that the data is accurate and precise.
