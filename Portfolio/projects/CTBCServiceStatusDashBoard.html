CTBCServiceStatusDashboard

The CTBC Service Status Dashboard is a centralized Web Monitoring Application designed to deliver real-time operational visibility across enterprise sites and servers. By executing automated system health checks at 5-minute intervals, the platform provides precise tracking of infrastructure uptime, instantly identifying active and inactive services to maintain continuous service availability.

Role Back end developer and Database Manager
Timeline13 weeks, 2026
StackC#, Python, MSSQL, Oracle Cloud Infrastructure
StatusDone

Overview

A centralized web app that monitors the operational status of enterprise sites and servers, providing real-time visibility into system health and service availability.

The problem

System admins often struggle to keep track of the operational status of multiple enterprise sites and servers. Manual checks are time-consuming and prone to error, leading to delayed responses to service disruptions. Mainly the previous web app is only based on frontend and most of it is hard coded and doesn't have a database to store the data.

What I built

Engineered an enterprise service status dashboard featuring a custom Flask backend, MSSQL database, and Oracle Cloud Infrastructure deployment. Assisted in building the C# frontend and handled cross-stack integration via RESTful API calls. The solution automates system health monitoring on 5-minute cycles, delivering precise uptime metrics and instant visibility into service availability.

What I learned

Working on this enterprise status dashboard provided me with my first hands-on experience in a professional corporate environment. Building a Flask API backend connected to MSSQL and deployed on Oracle Cloud Infrastructure taught me how to design robust, production-ready server architectures tailored to specific client requirements. On the client side, assisting with the C# frontend and wiring up the end-to-end integration via REST API calls gave me a practical understanding of full-stack data flow. Most importantly, implementing automated 5-minute health check routines deepened my knowledge of real-time monitoring, service uptime tracking, and building resilient systems that maintain continuous service availability.
