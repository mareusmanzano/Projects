Tablescraps

A recipe organizer that turns messy screenshots and links into clean, searchable recipe cards.

RoleSolo full-stack developer
Timeline2 weeks, 2026
StackReact, Supabase
StatusLive, personal project

Overview

Tablescraps takes the recipe screenshots and shared links that pile up in everyone's camera roll and turns them into a clean, searchable card library.

The problem

My own recipe collection was scattered across screenshots, browser bookmarks, and half-remembered posts. I wanted a single place to store and actually search them by ingredient.

What I built

I built a React app backed by Supabase for auth, storage, and a Postgres database. Users can paste a link or upload a screenshot; a parsing step extracts ingredients and steps into a structured, searchable card.

  • Link and image import with automatic ingredient extraction
  • Ingredient-based search across the whole collection
  • Tagging and simple meal-planning view

What I learned

This was my deepest dive yet into Supabase — particularly row-level security policies for making sure each user only ever sees their own recipes.
